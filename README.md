# HTML 바로보기

아이폰·아이패드에서 HTML 파일을 골라 바로 실행하는 웹앱(PWA)입니다.

- `.html` / `.htm` 파일 선택 → 즉시 실행
- 이미지·CSS가 딸린 HTML은 함께 선택하거나 폴더를 `.zip`으로 열기
- 최근 연 파일 20개를 기기에 저장 (서버로 업로드되지 않음)
- Safari **공유 → 홈 화면에 추가** 시 전체 화면 앱 + 오프라인 실행

## 배포
Settings → Pages → Deploy from a branch → `main` / `(root)` → Save
